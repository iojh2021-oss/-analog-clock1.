# داشبورد فارسی — ساعت، ارز، سکه و آب‌وهوا

این پروژه یک PWA موبایلی مستقل است؛ قرار نیست تصویر زمینه خود گوشی اندروید را عوض کند. بعد از نصب از مرورگر، برنامه در حالت مستقل (standalone) باز می‌شود و رابط شیشه‌ای خودش را دارد.

## امکانات فعلی
- رابط کاملاً فارسی و RTL
- سازگار با صفحه موبایل اندروید و Safe Area
- ساعت آنالوگ و دیجیتال
- تاریخ شمسی و نام ماه به‌صورت خودکار از تاریخ دستگاه
- پس‌زمینه عکس داخل خود اپ؛ انتخاب عکس از گالری/فایل‌های گوشی
- ذخیره عکس انتخابی داخل IndexedDB خود اپ و دکمه بازگردانی
- سه بخش: ساعت، ارز و سکه، آب‌وهوا
- آب‌وهوا فقط برای شهر انتخاب‌شده نمایش داده می‌شود
- انتخاب شهر از فهرست شهرهای مهم ایران
- پیش‌بینی ۷ روزه آب‌وهوا
- دلار، یورو و ارزهای مهم
- سکه بهار آزادی، نیم سکه و ربع سکه با ستون خرید/فروش و واحد تومان
- برای جلوگیری از نمایش عدد ساختگی، نرخ مالی وقتی منبع/API قیمت به پروژه متصل نشده باشد «—» است.

## فایل تست
test-ui.html نسخه تست همین رابط است و اکنون با نسخه شیشه‌ای و پس‌زمینه قابل‌تعویض هماهنگ شده است.

## نصب روی اندروید
پروژه را روی HTTPS مثل GitHub Pages منتشر کن و با Chrome باز کن؛ سپس Install app / افزودن به صفحه اصلی را بزن. display: standalone باعث می‌شود برنامه مثل یک اپ مستقل اجرا شود، نه اینکه تصویر زمینه گوشی را تغییر دهد.

## داده‌های آب‌وهوا
آب‌وهوا از Open-Meteo دریافت می‌شود و با انتخاب شهر، فقط مختصات همان شهر برای پیش‌بینی استفاده می‌شود.

## نرخ ارز و سکه
ساختار UI و اتصال منبع قیمت آماده است، اما نرخ بازار ایران نباید در کد ثابت یا ساختگی قرار داده شود. TGJU برای داده‌های بازار داخلی سرویس/وب‌سرویس ارائه می‌کند و برای استفاده برنامه‌ای نیاز به منبع و دسترسی مناسب دارد. در این نسخه آدرس API قیمت در تنظیمات قابل ثبت است.

## ساختار
- index.html — نسخه اصلی اپ
- test-ui.html — نسخه تست UI
- manifest.json — نصب به‌صورت PWA مستقل
- sw.js — کش و اجرای آفلاین پوسته
- icon-192.png و icon-512.png — آیکن‌ها
