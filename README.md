# ساعت آنالوگ — نسخه‌ی وب (PWA)

این یک اپ وب قابل‌نصب (Progressive Web App) هست. فایل `index.html` رو می‌تونی همین حالا
باز کنی و ساعت رو ببینی، اما برای **نصب واقعی روی صفحه‌ی اصلی اندروید** لازمه این فایل‌ها
(`index.html`, `manifest.json`, `sw.js`, دو آیکن) با هم روی یک آدرس HTTPS میزبانی بشن —
مرورگرها (کروم) فقط برای سایت‌های HTTPS گزینه‌ی نصب رو نشون می‌دن.

## سریع‌ترین راه میزبانی (رایگان، بدون نیاز به دانش فنی)
یکی از این‌ها رو انتخاب کن:

1. **Netlify Drop** — به آدرس https://app.netlify.com/drop برو و کل پوشه رو
   (هر ۵ فایل) بکش و رها کن. چند ثانیه بعد یه لینک HTTPS می‌گیری.
2. **GitHub Pages** — یه ریپازیتوری بساز، این فایل‌ها رو اضافه کن، و از تنظیمات
   ریپازیتوری، GitHub Pages رو فعال کن.
3. **Vercel** — مشابه Netlify، پوشه رو آپلود کن.

## نصب روی اندروید
1. لینک HTTPS رو با مرورگر Chrome گوشی باز کن.
2. منوی سه‌نقطه (⋮) رو بزن.
3. گزینه‌ی **افزودن به صفحه اصلی / Install app** رو انتخاب کن.
4. آیکن ساعت روی صفحه‌ی اصلی گوشی ظاهر می‌شه و مثل یک اپ مستقل باز می‌شه (بدون نوار آدرس مرورگر).

## فایل‌ها
- `index.html` — طراحی و منطق ساعت (Canvas + JavaScript)
- `manifest.json` — مشخصات اپ برای نصب (نام، آیکن، حالت نمایش)
- `sw.js` — Service Worker برای کارکرد آفلاین
- `icon-192.png`, `icon-512.png` — آیکن‌های اپ
